## 🎯 **THE VAST DIFFERENCE: CHORD TONES vs SCALE DEGREES**

### **⭕ CHORD TONES (CIRCLES) - CHORD-RELATIVE PERSPECTIVE**

**Definition:** Numbers relative to each individual chord's root  
**Characteristics:**
- **ALWAYS** 1-3-5-7 for any chord regardless of key context
- **CHANGES** with every chord change
- Shows the **INTERNAL ARCHITECTURE** of each chord
- Represents **HARMONIC FUNCTION** within that specific chord
- **Universal** across all keys and chord types

**Example - F Major Chord (IV in C Major):**
- ⭕ **1** = F (root of THIS chord)
- ⭕ **3** = A (major third of THIS chord)  
- ⭕ **5** = C (perfect fifth of THIS chord)
- ⭕ **7** = E (major seventh of THIS chord, if extended)

### **🔸 SCALE DEGREES (DIAMONDS) - KEY-RELATIVE PERSPECTIVE**

**Definition:** Numbers relative to the key center (tonic)  
**Characteristics:**
- **FIXED** to the key center regardless of current chord
- **NEVER CHANGES** throughout the key
- Shows **WHERE** each chord tone sits within the master key
- Represents **POSITIONAL RELATIONSHIP** to the key center
- **Context-dependent** on the established key

**Example - F Major Chord (IV in C Major):**
- 🔸 **4** = F (4th degree of C Major key)
- 🔸 **6** = A (6th degree of C Major key)
- 🔸 **1** = C (1st degree of C Major key - the tonic!)
- 🔸 **3** = E (3rd degree of C Major key, if extended)
