### **MANDATORY PERIODIC VALIDATION**
Every agent working on Harmonic Oracle **MUST** use the automated check-in system to prevent context drift:

```typescript
import AgentCheckInSystem from '@/utils/agentCheckIn';

// System auto-initializes and runs every 30 minutes
// Manual refresh when needed:

```

### **CHECK-IN TRIGGERS**
- **Every 30 minutes** during active work
- **Immediately** if context is >2 hours stale
- **Before major changes** to protected paths
- **When starting new tasks** or switching focus
- **After encountering errors** or unexpected behavior

1. ✅ **Sentinel Validation** - Confirms critical code markers present
2. ✅ **Protected Path Check** - Validates no unauthorized modifications
3. ✅ **Git Status Review** - Confirms clean repository state
4. ✅ **Priority Alignment** - Updates current task priorities
5. ✅ **Context Gap Analysis** - Identifies missing knowledge areas

### **REQUIRED ACTIONS ON CHECK-IN FAILURE**
