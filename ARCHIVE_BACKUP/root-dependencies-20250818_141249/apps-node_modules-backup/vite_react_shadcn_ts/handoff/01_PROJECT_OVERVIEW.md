# PROJECT OVERVIEW - HARMONIC ORACLE

## 🎵 What Is Harmonic Oracle?

Harmonic Oracle is a **musical data analysis and visualization platform** that transforms chord progressions into interactive harmonic visualizations. It processes musical data through sophisticated pipelines and presents insights via two primary interfaces:

1. **Million Song Mind (MSM)** - Tabular explorer with filtering, search, and harmonic profiling
2. **Braid Visualization** - Geometric SVG representation of harmonic relationships

## 📊 Data Flow Architecture

### Input Sources
1. **CPML Files** - Legacy chord progression markup
2. **Data2 CSV** - Intermediate format with basic metadata
3. **Spotify API** - Artist/song enrichment
4. **MusicBrainz/Discogs** - Fallback metadata sources

### Processing Pipeline
```
Raw Data → Parsing → Key Detection → Roman Numeral Assignment → HUV Generation → Data3 Output
```

### Output Formats
1. **Data3 Pure CSV** - Canonical format with 27 HUV columns
2. **Names Patch CSV** - Metadata enrichment sidecar
3. **JSON Assets** - Braid tonality configurations

## 🎵 Musical Domain Knowledge

### Key Concepts
- **Roman Numerals:** I, ii, iii, IV, V, vi, vii° (major), i, ii°, bIII, iv, v, bVI, bVII (minor)
- **HUV Vectors:** 5-tuple encoding (total, root, first, second, third inversions)
- **Chord Extensions:** dom7, maj7, sus4, add9, color-tones
- **Key Detection:** Krumhansl-Schmuckler + "Final Boss" Other-minimization

### Data Precision Requirements
- **Exact Roman Numeral Mapping:** No ambiguity in chord-to-slot assignment
- **Inversion Tracking:** Precise voice-leading analysis
- **Key Consistency:** All chords analyzed in detected key context
- **Extension Support:** Future-ready for jazz/complex harmony
