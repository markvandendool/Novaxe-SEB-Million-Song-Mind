## 🤖 CI/CD Pipeline

### GitHub Actions Workflow (`.github/workflows/pr-guard.yml`)
```yaml
name: PR Guard
on: [pull_request]

jobs:
  guard:
    runs-on: ubuntu-latest
    steps:
      # 1. Build verification
      - run: pnpm i --frozen-lockfile
      - run: pnpm build
      
      # 2. Sentinel validation
      - run: |
          grep -R "msm:pendingUpload" src/pages/Index.tsx
          grep -R "parseUnifiedCSVData:start" src/utils/cpmlParser.ts
          grep -R "harmonic_fingerprint" src/lib/utils.ts
          
      # 3. Protected path enforcement
      - name: Check braid modifications
        run: |
          if git diff --name-only ${{ github.event.pull_request.base.sha }}..HEAD \
                | grep -E '^src/(components/braid|pages/Braid)'; then
            if ! gh pr view --json labels | jq -r '.labels[].name' | grep -q "allow-braid"; then
              echo "Braid code modified without allow-braid label"
              exit 1
            fi
          fi
```

### Status Checks Required
- ✅ **Build Success:** `pnpm build` exits 0
- ✅ **Type Check:** TypeScript compilation clean
- ✅ **Sentinel Preservation:** Critical markers present
- ✅ **Protected Path Review:** CODEOWNER approval for sensitive files

## 🚨 Merge Conflict Resolution

### Common Conflict Scenarios
1. **Package.json conflicts** - Usually auto-resolvable
2. **Import statement conflicts** - Merge both imports
3. **Component prop conflicts** - Preserve both feature sets
4. **Data format conflicts** - NEVER break Data3 schema

### Resolution Process
```bash
# Start merge/rebase
git rebase origin/main

# For each conflict:
# 1. Open conflicted file
# 2. Look for <<<<<<< markers
# 3. Choose or combine changes
# 4. Remove conflict markers
# 5. Test the resolution

# Continue rebase
git add .
git rebase --continue

# Verify build still works
pnpm build
pnpm dev

# Push resolved changes
git push --force-with-lease
```

### Conflict Prevention
- **Regular rebasing** - Keep branches current
- **Small commits** - Easier to resolve conflicts
- **Clear communication** - Coordinate with other agents
- **Feature isolation** - Minimize overlapping changes

## ⚠️ Emergency Procedures

### Build Failure Recovery
```bash
# Reset to last known good state
git log --oneline -5
git reset --hard <good-commit-hash>

# Force push (only if safe)
git push --force-with-lease
```

### Accidental Main Push
```bash
# NEVER DO THIS - but if it happens:
# 1. Immediately contact project owner
# 2. Document what was pushed
# 3. Prepare rollback plan
# 4. Create hotfix PR to resolve
```

### Lost Work Recovery
```bash
# Find lost commits
git reflog

# Recover lost work
git checkout <lost-commit-hash>
git checkout -b recovery-branch

# Cherry-pick needed changes
git cherry-pick <commit-hash>
```
