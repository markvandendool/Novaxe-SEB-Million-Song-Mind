# BRAID SYSTEM - HARMONIC ORACLE

## 🎨 Overview

The Braid System is Harmonic Oracle's signature visualization, representing harmonic relationships through geometric SVG patterns. It ports exact Angular geometry from the GitLab `nvx_braid_fixes2` branch into React components.

---

## 🏗️ Braid Architecture

### Braid Variants
```
BraidTonal.tsx    → Classic/Tonal braid (primary implementation)
BraidClassic.tsx  → Blues braid (scaffold)  
BraidNew2.tsx     → Hive/NEW2 braid (scaffold)
BraidLiveMetrics.tsx → Dynamic metrics braid (in development)
```

## 🎯 BraidTonal Component (Primary)

### Purpose
Renders the Classic/Tonal braid with exact SVG geometry matching the GitLab Angular source.

### Key Features
- **Tonality Selection:** Dropdown for key selection (C, G, D, A, E, B, F#, etc.)
- **Roman Toggle:** Switch between note names (C, D, E) and Roman numerals (I, ii, iii)
- **Interactive Bubbles:** Click handlers for chord selection
- **Exact Geometry:** Pixel-perfect match to Angular original

### Component Structure
```typescript
// src/components/braid/BraidTonal.tsx
const BraidTonal: React.FC = () => {
  const [selectedTonality, setSelectedTonality] = useState('C');
  const [displayRoman, setDisplayRoman] = useState(false);
  const [tonalityData, setTonalityData] = useState<TonalityData[]>([]);
  
  // Load braid_tonalities.json
  useEffect(() => {
    fetch('/assets/braid_tonalities.json')
      .then(res => res.json())
      .then(data => setTonalityData(data[selectedTonality] || []));
  }, [selectedTonality]);
  
  return (
    <section id="braid-tonal" style={{background: '#343a40', color: 'white'}}>
      {/* Tonality selector */}
      <select onChange={(e) => setSelectedTonality(e.target.value)}>
        {TONALITIES.map(key => (
          <option key={key} value={key}>{key}</option>
        ))}
      </select>
      
      {/* Roman numeral toggle */}
      <label>
        <input 
          type="checkbox" 
          checked={displayRoman}
          onChange={(e) => setDisplayRoman(e.target.checked)} 
        />
        Display Roman Numerals
      </label>
      
      {/* SVG braid */}
      <div className="braid">
        <svg viewBox="-10 40 320 1600" xmlns="http://www.w3.org/2000/svg">
          {/* SVG content */}
        </svg>
      </div>
    </section>
  );
};
```

interface TonalityItem {
  note: string;
  roman: string;
  x: number;

const loadTonalityData = async (key: string): Promise<TonalityItem[]> => {
  try {
    const response = await fetch('/assets/braid_tonalities.json');

const renderBraidElements = (tonalityData: TonalityItem[]) => {

const renderSmallBubbles = (item: TonalityItem, index: number) => {
  // Logic for positioning small comma shapes around main bubble
  const positions = calculateSmallBubblePositions(item);
  
  return positions.map((pos, i) => (
    <use
      key={`small-${index}-${i}`}
      href={pos.side === 'left' ? '#leftCommaSM' : '#rightCommaSM'}
      transform={`translate(${pos.x}, ${pos.y}) rotate(${pos.rotation})`}
      fill={`url(#greyGradient${(index + i) % 10})`}
    />
  ));

### Connection Rendering
```typescript
const renderConnections = (item: TonalityItem, index: number, allItems: TonalityItem[]) => {
  const connections = calculateConnections(item, allItems);
  
  return connections.map((conn, i) => {
    const isVertical = Math.abs(conn.dx) < Math.abs(conn.dy);
    const rectId = isVertical ? '#rectV' : (conn.dx > 0 ? '#rectHright' : '#rectHleft');
    
    return (
      <use
        key={`conn-${index}-${i}`}
        href={rectId}
        transform={`translate(${conn.x}, ${conn.y}) rotate(${conn.angle})`}
        fill="url(#greyGradient)"
        opacity="0.6"
      />
    );
  });
};
```

## 🔄 Live Metrics Integration

### BraidLiveMetrics Component
**Purpose:** Dynamic braid with bubble scaling and progression arrows

**Key Features:**
- **Bubble Scaling:** Size based on chord frequency data
- **Progression Arrows:** Width based on transition frequency  
- **View Modes:** Presence → Only → Progression toggle
- **Real-time Data:** Integration with Data3 Pure HUV vectors

### Component Structure
```typescript
// src/components/braid/BraidLiveMetrics.tsx
interface ChordData {
  chord: string;
  count: number;
  only_count?: number;
}

interface ProgressionData {
  from: string;
  to: string;
  count: number;
}

const BraidLiveMetrics: React.FC<{
  songData?: {
    chords: ChordData[];
    progressions: ProgressionData[];
  };
  onBubbleClick?: (chord: string) => void;
}> = ({ songData, onBubbleClick }) => {
  const [viewMode, setViewMode] = useState<'presence' | 'only' | 'progression'>('presence');
  
  // Calculate bubble sizes based on data
  const getBubbleRadius = (chord: ChordData) => {
    const count = viewMode === 'only' ? (chord.only_count || 0) : chord.count;
    const maxCount = Math.max(...chordData.map(c => viewMode === 'only' ? (c.only_count || 0) : c.count));
    const ratio = count / maxCount;
    return 20 + (ratio * 40); // 20-60px radius range
  };
  
  // Calculate arrow thickness for progressions
  const getArrowWidth = (progression: ProgressionData) => {
    const maxProgCount = Math.max(...progressions.map(p => p.count));
    const ratio = progression.count / maxProgCount;
    return 2 + (ratio * 8); // 2-10px width range
  };
  
  return (
    <div className="braid-live-metrics">
      {/* View mode toggle */}
      <button onClick={cycleViewMode}>
        {viewMode.charAt(0).toUpperCase() + viewMode.slice(1)} View
      </button>
      
      {/* Dynamic SVG with scaled elements */}
      <svg viewBox="0 0 800 600">
        {/* Render chord bubbles with dynamic sizing */}
        {chordData.map((chord, i) => {
          const radius = getBubbleRadius(chord);
          const x = (i % 6) * 130 + 65;
          const y = Math.floor(i / 6) * 120 + 60;
          
          return (
            <g key={chord.chord} onClick={() => onBubbleClick?.(chord.chord)}>
              <circle
                cx={x}
                cy={y}
                r={radius}
                fill="url(#dynamicGradient)"
                className="cursor-pointer transition-all duration-300 hover:opacity-80"
              />
              <text x={x} y={y + 5} textAnchor="middle" className="font-fontdec13 text-white">
                {chord.chord}
              </text>
              <text x={x} y={y + 20} textAnchor="middle" className="font-fontdec13 text-xs text-gray-300">
                {viewMode === 'only' ? (chord.only_count || 0) : chord.count}
              </text>
            </g>
          );
        })}
        
        {/* Render progression arrows (only in progression mode) */}
        {viewMode === 'progression' && progressions.map((prog, i) => {
          const width = getArrowWidth(prog);
          // Calculate arrow path between chords
          const path = calculateProgressionPath(prog.from, prog.to, chordData);
          
          return (
            <path
              key={`${prog.from}-${prog.to}`}
              d={path}
              stroke="rgba(255,255,255,0.7)"
              strokeWidth={width}
              fill="none"
              markerEnd="url(#arrowhead)"
            />
          );
        })}
      </svg>
    </div>
  );
};
```

## ⚠️ Critical Considerations

### Geometry Precision
- **Exact Coordinates:** All x,y positions must match GitLab source exactly
- **Transform Accuracy:** Scale, translate, rotate values must be precise
- **ViewBox Consistency:** ViewBox dimensions affect all relative positioning

### Performance Optimization
- **SVG Reuse:** Use `<use>` elements for repeated shapes
- **Gradient Caching:** Reuse gradient definitions across elements
- **Event Delegation:** Minimize individual click handlers

### Data Integration
- **HUV Mapping:** Connect braid positions to Data3 Pure HUV slots
- **Real-time Updates:** Efficiently update bubble sizes without full re-render
- **Memory Management:** Clean up event listeners and data subscriptions

### Cross-browser Compatibility
- **SVG Support:** Ensure consistent rendering across browsers
- **Font Fallbacks:** Provide fallback fonts for Fontdec13
- **Touch Events:** Support both mouse and touch interactions

---

**The Braid System is the visual heart of Harmonic Oracle. All modifications must preserve exact geometric relationships while enhancing musical functionality and user experience.**
