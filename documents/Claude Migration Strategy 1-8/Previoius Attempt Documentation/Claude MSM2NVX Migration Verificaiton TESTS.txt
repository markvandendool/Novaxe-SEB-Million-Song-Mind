## 🔧 **TROUBLESHOOTING GUIDE**

### **Issue 1: Build Fails**
```bash
# Check Node.js version
node --version  # Should be 18+ for modern Lit

# Clear and reinstall dependencies
rm -rf node_modules package-lock.json
npm install

# Try build again
npm run build
```

### **Issue 2: Browser Errors**
```javascript
// Common fixes for browser issues:

// 1. Check if modules are loaded
console.log('Lit loaded:', !!window.lit);
console.log('Tonal loaded:', !!window.Tonal);

// 2. Check for CORS issues (if serving files)
// Use: python3 -m http.server 8080
// Don't use: file:// URLs

// 3. Check for Web Components support
console.log('Custom elements supported:', !!window.customElements);
```
