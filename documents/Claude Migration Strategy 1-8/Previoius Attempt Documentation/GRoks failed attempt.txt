What This Does and Why It Works

All previous steps remain to clean, pin versions (now using exact "typescript": "4.1.6" for stability), and configure.
After install, the find/sed command patches all @tonaljs d.ts files: It searches for lines containing 'export {' and removes 'type ' from them (e.g., 'type NoNote' becomes 'NoNote'), fixing the parse error without affecting type definitions like 'type Foo ='. This allows the compiler to parse the files, and with skipLibCheck: true, it bypasses any resulting type mismatches.
Serves the app as before.
