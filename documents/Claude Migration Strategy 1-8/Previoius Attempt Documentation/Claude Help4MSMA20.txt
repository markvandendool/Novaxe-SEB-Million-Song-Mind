## Troubleshooting the Connection Refused Issue

The most likely causes and solutions:

1. **Stale terminal output**: Your terminal shows "VITE ready" from a previous run, but the actual process died. The dev script handles this.

2. **Port conflicts**: Another process is holding the port. The script kills these processes.

3. **Vite cache corruption**: Old cache files can cause port binding issues. The script clears these.

4. **macOS firewall**: If the script still fails, check:
   ```bash
   # Check firewall status
   sudo /usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate
   
   # Allow node/npm through firewall if needed
   sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /usr/local/bin/node
   ```
