Here's a comprehensive prompt for using the Mac Pro via SSH commands:

## SSH Connection to Mac Pro

### Basic Connection
```bash
ssh username@mac-pro-ip-address
```

### With Specific Port (if not default 22)
```bash
ssh -p 2222 username@mac-pro-ip-address
```

### With Key Authentication
```bash
ssh -i /path/to/private_key username@mac-pro-ip-address
```

### Enable X11 Forwarding (for GUI apps)
```bash
ssh -X username@mac-pro-ip-address
```

### Enable Compression (for slow connections)
```bash
ssh -C username@mac-pro-ip-address
```

## Essential Commands Once Connected

### System Information
```bash
# Check system info
system_profiler SPHardwareDataType

# Check macOS version
sw_vers

# Check disk space
df -h

# Check memory usage
top -l 1 | head -n 10

# Check running processes
ps aux | head -20
```

### File Management
```bash
# Navigate to project directory
cd "/Users/markvandendool/HarmonicOracle GitHub/Novaxe SEB"

# List files with details
ls -la

# Check current directory
pwd

# Create directory
mkdir new_project

# Copy files
cp source_file destination_file

# Move/rename files
mv old_name new_name

# Remove files
rm filename
rm -rf directory_name
```

### Node.js and Development Tools
```bash
# Check Node version
node --version
npm --version

# Use nvm to switch Node versions
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
nvm list
nvm use 16.20.2

# Install dependencies
npm install --legacy-peer-deps

# Run development server
npm start
./node_modules/.bin/ng serve --host 0.0.0.0 --port 4202
```

### Process Management
```bash
# Check what's running on specific port
lsof -i :4202
lsof -i :8080

# Kill process by PID
kill -9 PID_NUMBER

# Kill process by port
lsof -ti:4202 | xargs kill -9

# Check running processes
ps aux | grep node
ps aux | grep ng
```

### Network and Services
```bash
# Check network connections
netstat -an | grep LISTEN

# Test connectivity
ping google.com

# Check if service is running
curl -I http://localhost:4202
curl -I http://localhost:8080
```

### File Editing (via command line)
```bash
# Edit files with nano
nano package.json

# Edit files with vim
vim angular.json

# View file contents
cat filename
head -20 filename
tail -20 filename

# Search in files
grep "search_term" filename
grep -r "search_term" directory/
```

### Git Operations
```bash
# Check git status
git status

# Check current branch
git branch

# Switch branches
git checkout branch_name

# Pull latest changes
git pull origin main

# Commit changes
git add .
git commit -m "Fix Angular 11 dependencies"

# Push changes
git push origin main
```

### Package Management
```bash
# Clean npm cache
npm cache clean --force

# Remove node_modules and reinstall
rm -rf node_modules package-lock.json
npm install

# Update packages
npm update

# Install specific package
npm install package_name@version
```

### System Maintenance
```bash
# Check system load
uptime

# Check disk usage
du -sh *

# Find large files
find . -size +100M

# Check system logs
tail -f /var/log/system.log
```

### Troubleshooting Commands
```bash
# Check if port is in use
lsof -iTCP:4202 -sTCP:LISTEN -P -n

# Test if server is responding
curl -sS http://127.0.0.1:4202/ | head -n 20

# Check Angular CLI version
./node_modules/.bin/ng version

# Validate package.json
npm run lint

# Check for syntax errors
npx tsc --noEmit
```

### Exit and Disconnect
```bash
# Exit SSH session
exit

# Or use Ctrl+D
```

## Example Workflow for Angular Project
```bash
# Connect to Mac Pro
ssh username@mac-pro-ip-address

# Navigate to project
cd "/Users/markvandendool/HarmonicOracle GitHub/Novaxe SEB"

# Switch to correct Node version
export NVM_DIR="$HOME/.nvm"; [ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"; nvm use 16.20.2

# Clean install
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps

# Kill existing processes
lsof -ti:4202 | xargs kill -9 2>/dev/null || true

# Start development server
./node_modules/.bin/ng serve --host 0.0.0.0 --port 4202

# Check if running
curl -I http://localhost:4202
```
