Overarching summary: purpose, intent, and how the app realizes them
- Purpose: A musical analysis and visualization platform that renders complex braid visualizations, harmonic key contexts, and live corpus metrics, enabling exploration of tonalities, chord progressions, and 3D topologies.
- Intent realization:
  - Feature pages: Classic/Tonal/New braid visualizations and Live Metrics.
  - Domain state: Global key context and locks between user key and score key.
  - Rendering: High-performance SVG and Three.js for 3D braid geometry.
  - UI/UX: Headless primitives (Radix) in React; replaced with Angular CDK/Material + Tailwind in Angular.
  - Extensibility: Modular services for harmonic mapping, parsing, and layout math; NgRx store for deterministic state and time-travelable debugging.

Target Angular 15 project structure (future repo)
- Approach: Classic Angular modules (NgModule) for wide library compatibility. OnPush across all components. Tailwind for theming. NgRx for app state. Direct three.js integration for tight control.

import { createReducer, on } from '@ngrx/store';
import * as KeyActions from './global-key.actions';

export interface GlobalKeyState {
  tonality: string;
  scoreTonality: string;
  isLockedToScore: boolean;
}
export const initialState: GlobalKeyState = {
  tonality: 'C',
  scoreTonality: 'C',
  isLockedToScore: false,
};
export const globalKeyReducer = createReducer(
  initialState,
  on(KeyActions.setTonality, (s, { tonality }) => ({ ...s, tonality })),
  on(KeyActions.setScoreTonality, (s, { scoreTonality }) => ({ ...s, scoreTonality })),
  on(KeyActions.toggleLock, s => ({ ...s, isLockedToScore: !s.isLockedToScore })),
);

SEO best practices (Angular)
// core/services/seo/seo.service.ts
import { Injectable } from '@angular/core';
import { Meta, Title } from '@angular/platform-browser';

@Injectable({ providedIn: 'root' })
export class SeoService {
  constructor(private title: Title, private meta: Meta) {}
  setMeta(opts: { title: string; description?: string; canonicalUrl?: string }) {
    this.title.setTitle(opts.title);
    if (opts.description) {
      this.meta.updateTag({ name: 'description', content: opts.description });
    }
    if (opts.canonicalUrl) {
      let link: HTMLLinkElement | null = document.querySelector("link[rel='canonical']");
      if (!link) {
        link = document.createElement('link');
        link.setAttribute('rel', 'canonical');
        document.head.appendChild(link);
      }
      link.setAttribute('href', opts.canonicalUrl);
    }
  }
}

// core/services/seo/jsonld.service.ts
import { Injectable } from '@angular/core';
@Injectable({ providedIn: 'root' })
export class JsonLdService {
  set(data: object) {
    const scriptId = 'app-structured-data';
    let script = document.getElementById(scriptId) as HTMLScriptElement | null;
    if (!script) {
      script = document.createElement('script');
      script.type = 'application/ld+json';
      script.id = scriptId;
      document.head.appendChild(script);
    }
    script.text = JSON.stringify(data);
  }
}

Three.js integration (Angular component)
// features/braid-3d/components/braid-three/braid-three.component.ts
import { AfterViewInit, Component, ElementRef, OnDestroy, ViewChild } from '@angular/core';
import * as THREE from 'three';

@Component({
  selector: 'app-braid-three',
  templateUrl: './braid-three.component.html',
})
export class BraidThreeComponent implements AfterViewInit, OnDestroy {
  @ViewChild('canvas', { static: true }) canvasRef!: ElementRef;
  private renderer!: THREE.WebGLRenderer;
  private scene = new THREE.Scene();
  private camera = new THREE.PerspectiveCamera(75, 1, 0.1, 1000);
  private frameId: number | null = null;

  ngAfterViewInit(): void {
    const canvas = this.canvasRef.nativeElement;
    this.renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
    this.resize();
    window.addEventListener('resize', this.resize);
    this.initScene();
    this.animate();
  }

  private initScene() {
    const ambient = new THREE.AmbientLight(0x404040); this.scene.add(ambient);
    const dir = new THREE.DirectionalLight(0xffffff, 1); dir.position.set(1,1,1); this.scene.add(dir);
    const geo = new THREE.TorusGeometry(1.5, 0.5, 16, 100);
    const mat = new THREE.MeshPhongMaterial({ color: 0xff0000 });
    this.scene.add(new THREE.Mesh(geo, mat));
    this.camera.position.z = 5;
  }

  private animate = () => {
    this.frameId = requestAnimationFrame(this.animate);
    this.renderer.render(this.scene, this.camera);
  };

  private resize = () => {
    const canvas = this.canvasRef.nativeElement;
    const w = canvas.clientWidth || 800, h = canvas.clientHeight || 600;
    this.camera.aspect = w / h; this.camera.updateProjectionMatrix();
    this.renderer.setSize(w, h, false);
  };

  ngOnDestroy(): void {
    if (this.frameId) cancelAnimationFrame(this.frameId);
    window.removeEventListener('resize', this.resize);
    this.renderer.dispose();
  }
}

- Unit: Jasmine/Karma or Jest (recommended with Nx). 80%+ coverage in core services and store reducers/selectors.

- E2E: Cypress with route-level fixtures mirroring current datasets.

Migration strategy (future-proof, low risk)
1) Greenfield repo + domain lib extraction
- Create new Angular repo. Extract domain logic (harmonic mapping, chord parsing, braid geometry math) into a pure TypeScript library (shared between React and Angular during transition). Publish as internal npm package or submodule.
2) Strangler pattern
- Route-level proxy: keep React app in production; progressively add Angular app served on subpaths (reverse proxy, or Module Federation shell if desired).
3) Parity-first milestones
- Define acceptance tests from current UI: Classic/Tonal/New/Live Metrics. Record cypress tests in React now, port as black-box tests against Angular to ensure parity.
4) State contracts
- Define JSON contracts for state slices (globalKey, braid state, metrics). Snapshot state before/after interactions in React; assert same in Angular effects/reducers.
5) Visualization equivalence
- For SVG: snapshot tests of generated DOM structure; for Three.js: deterministic seeds and camera to compare renders or mesh counts.
6) Performance budgets
- FPS budget for 3D (>55fps mid-tier), main-thread idle >60% on heavy interactions, cold-start <2.5s.
7) Accessibility and i18n
- WCAG AA for pages; i18n scaffolding via @angular/localize, keys stored centrally.
8) CI/CD and releases
- Lint, typecheck, unit, e2e, build, Lighthouse CI. Versioning with changesets. Canary releases gated behind feature flags.
