# Onboarding Guide for New Agents

Welcome to the Novaxe-SEB-Million-Song-Mind project. This guide will help you get fully caught up and ready to contribute at a forensic engineering level.

## Steps
1. Review the forensic log in `/documents/logs/forensic-log.md`.
2. Read all credential, API, and SSH documentation (redacted for security).
3. Review all attempts and actions in `/documents/attempts/`.
4. Follow security best practices for handling credentials and sensitive data.
5. Contact the lead agent for access requests or questions.

## Notes
- All documentation is updated hourly.
- Do not share credentials or sensitive information outside approved channels.
