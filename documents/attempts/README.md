# Attempts, Actions, and Locations

This folder contains records of all major actions, attempts, successes, failures, and file locations for forensic traceability.

## Format
- **Timestamp**
- **Agent**
- **Action/Attempt**
- **Result (Success/Failure)**
- **Location/Path**
- **Notes**

Refer to `/documents/logs/forensic-log.md` for the running log.
